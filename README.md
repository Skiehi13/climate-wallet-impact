# The Climate Tax Nobody's Talking About

Interactive presentation on hidden climate costs: therapy, emergency supplies, funeral services.

## Files
- `index.html` - Main webpage
- `style.css` - All styling
- `script.js` - Calculators and interactivity
- `SCRIPT.md` - Presentation narration (7.5 min)

## Quick Start
1. Download all 4 files to same folder
2. Open `index.html` in browser (Chrome/Firefox recommended)
3. Test all three calculators work
4. Follow SCRIPT.md for recording

## GitHub Pages Deployment

**Upload to GitHub:**
1. Create new repository on github.com
2. Upload all 4 files
3. Settings → Pages → Deploy from main branch
4. Wait 2-3 minutes
5. Visit `https://yourusername.github.io/repo-name/`

## Troubleshooting

**Nothing showing?**
- Make sure all 3 files (HTML, CSS, JS) are in same folder
- Try different browser
- Check browser console (F12) for errors
- Disable browser extensions

**Calculators not working?**
- Verify script.js is loading
- Check browser console for errors
- Make sure JavaScript is enabled

## Recording Tips
- Use Kaltura Capture or screen recorder
- Target 6-8 minutes (script is 7.5 min)
- Test all calculators before recording
- Follow SCRIPT.md timing markers
- Don't rush the data/statistics
